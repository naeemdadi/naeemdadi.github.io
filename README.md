# Naeem Dadi

Personal portfolio site for [naeemdadi.github.io](https://naeemdadi.github.io/).

## Local development

```
npm install
npm run dev
```

## Deployment

Pushes to `master` run the GitHub Pages deployment workflow. Set **Settings > Pages > Build and deployment > Source** to **GitHub Actions** once before the first automated deployment.

## Content

Portfolio copy lives in `src/data/portfolio.js`. The résumé PDF is served from `public/resume.pdf`.

## Stack

- React (Create React App)
- Styled Components
- Sass
